# Changelog

Formato basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/).

## [Unreleased]

### Fixed
- E2E intermitentes que agotaban los 60 s esperando la app recién creada (sobre todo la primera prueba de la corrida, con la API en frío): si la lista aún no tenía datos, `invalidateQueries` reutilizaba el `GET` inicial en vuelo, que la API había leído antes del `POST`, y lo creado no aparecía nunca. Las mutaciones que refrescan una lista (apps, features, catálogo, enlaces) ahora cancelan el fetch en curso antes de invalidar.

### Fixed
- `infra/docker-compose.yml` usaba `minio/minio:latest`, que ya no existe en Docker Hub: el almacenamiento S3 de desarrollo es `rustfs/rustfs:1.0.4`.
- Al borrar un nodo o una conexión seleccionados, su id quedaba en la selección y el panel mostraba la ayuda al seleccionar otro elemento.
- Tras iniciar sesión se volvía siempre al inicio; ahora se vuelve a la página que se estaba abriendo.
- `pnpm --dir apps/web …` desde la raíz fallaba con corepack activo; un `package.json` mínimo en la raíz fija la versión de pnpm.
- Petición sin cuerpo o con JSON inválido respondía 500; ahora 400.
